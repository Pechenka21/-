Task Manager (PyQt6)
Desktop-приложение для управления задачами

Функционал
- Создание задачи с названием и описанием.
- Выбор приоритета (Low, Medium, High).
- Дополнительные настройки (Important, Send notification).
- Вывод созданных задач в окно приложения.
- Подсчет количества созданных задач.
- Удаление последней задачи.
- Фильтрация задач по приоритету.
